# Small evidence dictionary and recovery

| Evidence | Meaning / interpretation boundary |
| --- | --- |
| Official report | Exact set/version/content activity range, not upload month or provider-certified month. Users, Agents and relationship totals need not reconcile. Snapshots overlap and are non-additive. |
| Office observation | Independent refresh and inclusive D28 window; frozen paid identity, affiliation and licensing basis. Seven app counts overlap; overall activity and Chat are excluded. Weekly history is aggregate-only, never old people. |
| Department opportunity | Exact nullable company + department; API-owned positive/noReported/unknown partition of measured Office-active paid people. Unknown is not negative; no-reported is not never-used. |
| Peer edges | Exact API-ranked top three for the pinned group; used versus created distinct. Full pages include report-only edges; names do not identify sources or expertise. |
| About | Complete permitted long/native/short field for exact source member and generation. Declared purpose, not verified execution. Withheld content cannot be reconstructed from another source. |
| Origin/access | Current authoritative Microsoft/organization origin is separate from eligibility, description evidence and personal use permission. Unknown/conflict stays unknown. |
| Learning | generated_draft, description_suggestion, contributor_provided, contributor_confirmed are distinct assertions. Finite employee slots are safe projection; arbitrary staff prose is withheld. |
| Saved baseline | Bounded dated API aggregate and durable source identities, not a current metric owner, reusable read lease or original-person registry. |

## Failure recovery

- Missing/initializing optional source: use independent available evidence and explicitly
  qualify the draft. Automatic authenticated entry/retry owns collection; no manual gate.
- Expired/invalidated actor selection: preserve partial output and exact requested
  source intent; disclose incomplete retrieval and obtain new caller-bound reads
  explicitly. Do not merge old/new pages or silently change source/period.
- Missing/corrected/deleted durable source: retain unavailable/superseded state.
  Manual authored learning remains, but cannot resurrect source authority.
- Withheld/ambiguous: explain the state without recovering hidden identities or zeros.
- output_limit: smaller supported page with same context where possible; never clip
  About or declare success-shaped completeness. At most 32 calls/4 MiB/180 seconds;
  controlled three-peer/three-agent fixture target 16 calls/1 MiB. Over budget is limited.
- 401/claims challenge: supported per-user OAuth; 403: actual role/provider denial.
  429/503: respect retry timing and request ID. No token copying or cache deletion.
- Unknown create: retain timestamped UUID and canonical payload; only the user's
  explicit recovery retries that exact identity. Different payload conflicts.
  Read/update outcomes remain unknown until observed; never automatic mutation replay.
- Revision conflict: retain unsaved work, reload authorized record, and explicitly
  review before submitting the new expected revision.
