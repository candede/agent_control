# Future Ideas - Do Not Implement Now

This document is a parking lot, not an implementation prompt, roadmap phase, prerequisite, or acceptance checklist. Everything below is outside the current admin POC. Do not create code, schemas, permissions, infrastructure, disabled controls, feature flags, placeholder adapters, or tests for these ideas while executing the current manifest.

Reconsider an idea only after a new explicit scope decision identifies a real user need, cost/operational owner, and appropriate safety requirements. Being listed here is not approval to implement it later automatically.

## Possible future capabilities

| Idea                                                       | Reconsider when                                                                                           | Important boundary                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dataverse transcript viewing or collection                 | Administrators need conversation-level investigation that Microsoft's own tools cannot satisfy            | Live viewing is also sensitive processing. Define purpose, authorization, retention and privacy before introducing any content access; storage would require a separately reviewed protection and recovery design.                                                                                                                                               |
| Continuous Office 365 Management Activity ingestion        | On-demand Purview search is insufficient for an agreed history or monitoring requirement                  | Adds subscriptions, ingestion checkpoints, deduplication, expiry/gap handling and ongoing operations; do not activate a feed in this POC.                                                                                                                                                                                                                        |
| Scheduled inventory or hunting refresh                     | Measured use requires unattended freshness                                                                | Define application identity, tenant/data scope, API budget, job ownership and failure handling instead of silently reusing a user's delegated identity.                                                                                                                                                                                                          |
| Manual cross-source identity review and merge/split tools  | Real unmatched records materially prevent administrative workflows                                        | Preserve native IDs, authorization boundaries and reviewed history. Exact-ID matching remains the current limit.                                                                                                                                                                                                                                                 |
| Cryptographic audit tamper evidence                        | A concrete audit/compliance requirement exceeds append-only application records and managed logs          | Independently evaluate managed facilities before creating custom chains, signatures, external checkpoints or signing services.                                                                                                                                                                                                                                   |
| Higher availability and zero-downtime releases             | Measured availability targets justify their cost                                                          | Revisit extra instances, deployment slots, coordinated promotion and failover only with proven database/worker behavior.                                                                                                                                                                                                                                         |
| Independently hosted frontend                              | Static Web Apps or another frontend service provides a specific benefit worth a separate release boundary | Current production serves React and the API from one App Service artifact and origin.                                                                                                                                                                                                                                                                            |

Cosmos free tier depends on subscription eligibility and creation choices and excludes serverless; partitioning, transactions, queries and migration must be redesigned/proven. SQLite requires a suitable local persistent filesystem, not App Service's mounted network share. |
| Certificate or federated Entra app credentials             | Organizational policy or credential operations justify replacing the supported current credential setup   | Use native identity libraries and one selected credential mode; never add fallback modes merely for optional future flexibility.                                                                                                                                                                                                                                 |

Current tokens stay in memory, and delegated jobs wait for the initiating user's reauthentication after restart.                                                                                                                                                                                                  |
| Interactive maintenance tooling                            | Operators repeatedly need safe self-service actions beyond status and runbooks                            | Add specific authorized commands, not a general-purpose workflow/operations platform.                                                                                                                                                                                                                                                                            |
| Short-lived diagnostic payload capture                     | A reproducible provider problem cannot be understood from allowlisted fields and safe metadata            | Require explicit authorization, strict minimization and expiry. This is not approval for an unrestricted raw-data archive.                                                                                                                                                                                                                                       |

## Intentionally not queued

An arbitrary KQL editor, webhook ingestion alongside polling, a generic multi-database/provider framework, custom content encryption without a content feature, and extensive per-file completion bookkeeping have no current demonstrated need. Do not treat removing them as unfinished implementation work. Use Microsoft portals for unrestricted investigations and concise phase handoffs for the current campaign.

## Current execution boundary

Only the numbered files in the README's ordered implementation manifest are executable. Future ideas do not appear as unavailable POC capabilities: they are absent from the app, its grants, deployment resources and completion requirements. The current manifest still ends with authorized production deployment and observation of the retained features.
