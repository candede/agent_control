Microsoft sources were rechecked on 2026-09-09. ## Evidence interpretation

- `documented` means the cited Microsoft source described the operation or permission on the inventory date.
- Missing live evidence is reported separately from exact registry decisions such as `not_configured`, `missing_internal_role`, `preview_disabled`, or `unknown`. Only a current successful provider probe can establish `available` for a delivered read adapter.
- A permission listing does not prove tenant consent, licensing, role assignment, national-cloud support, API stability, or successful access to tenant data.
- Microsoft access tokens are an opaque client contract. Runtime evidence uses validated MSAL response metadata and returned delegated scopes or safely exposed application roles; readable token claims can reject contradictions but are not required for a valid provider response.
- Evidence is principal-, resource-, mode-, permission-, contract-, configuration-, and environment-specific. It expires after five minutes, immediately becomes unauthorized, and remains stale diagnostic history only until explicit operator retention.
- Preview/beta contracts can change without compatibility guarantees. They require a new dated review before production enablement.
- Package write qualification follows [the reversible canary protocol](mutation-canaries.md). Phase 05 performed no live provider write, so package block remains `preview_disabled`; access and reassignment remain disabled by their operation-specific safety gates. Saved reads remain independently usable.
- Purview Audit Search selects `POST /v1.0/security/auditLog/queries` with singular `serviceFilter`, a required subset of code-owned preset operations, direct create/get objects, and collection envelopes for query/record lists. Microsoft's resource page still says plural `serviceFilters`, while single-query GET still lists `ThreatIntelligence.Read.All`. GET response prose describes a direct object but its example wraps an object in `value` and includes `keywordFilter`; that example shape is rejected. Agent Control neither sends fallback shapes nor requests the unrelated permission. A separately approved lifecycle using `AuditLogsQuery.Read.All` must qualify create, poll and records for each mode. No live query ran in Phase 07.
- Purview projection version 1 treats the Graph `auditLogRecord` as an outer wrapper and the native Office audit object as a separate schema. Graph documents wrapper `userType` as a string enum, but Office documents native `UserType` as `Edm.Int32` values 0-10; the native value is validated but not exposed. Office record types `256` and `261` identify `PowerPlatformAdministratorActivity` and `CopilotInteraction`. Copilot metadata is read only below `CopilotEventData`; message metadata follows the newer emitted JSON casing `Messages[].ID` and `Messages[].isPrompt`. The Graph `defaultAuditData` page defines no native child properties, and the older Copilot schema uses conflicting message casing, so no aliases or undocumented fields are projected. [Graph wrapper](https://learn.microsoft.com/en-us/graph/api/resources/security-auditlogrecord?view=graph-rest-1.0), [default audit data](https://learn.microsoft.com/en-us/graph/api/resources/security-defaultauditdata?view=graph-rest-1.0), [Office common schema](https://learn.microsoft.com/en-us/office/office-365-management-api/office-365-management-activity-api-schema), [Copilot schema](https://learn.microsoft.com/en-us/office/office-365-management-api/copilot-schema), [emitted Copilot example](https://learn.microsoft.com/en-us/purview/audit-copilot).
- Defender hunting uses only `POST /v1.0/security/runHuntingQuery` with exact `Query` and `Timespan` body keys. The application accepts no `workspaceId`; Graph-selected primary-workspace fallback therefore cannot be presented as requested-workspace isolation. Code-owned `AgentsInfo` and Agent 365 `CloudAppEvents` projections are capped at 200 retained rows and 2 MB. `AgentsInfo` remains preview. Delegated consent remains subject to Defender RBAC/data-source assignment, and empty success cannot identify a missing license, connector, table or rollout. Original dynamic objects, raw events, messages, instructions, memory and tool content are discarded. [Graph operation](https://learn.microsoft.com/en-us/graph/api/security-security-runhuntingquery?view=graph-rest-1.0), [AgentsInfo](https://learn.microsoft.com/en-us/defender-xdr/advanced-hunting-agentsinfo-table), [CloudAppEvents](https://learn.microsoft.com/en-us/defender-xdr/advanced-hunting-cloudappevents-table), [runbook](defender-agent365-hunting.md).

Current lifecycle evidence proves exact API access, not all entitlements or complete event coverage, especially for empty results.
